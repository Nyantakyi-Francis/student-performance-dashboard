# School workflow walkthrough

[Open the application](https://student-performance-dashboard-three.vercel.app/) | [Watch the recording](assets/school-workflow.mp4)

The recording uses the verified production build and the same fictional school as the public demo. The recording is 58 seconds long and has no audio.

1. Explore the sample dashboard and its term/subject filters.
2. Open School workspace and try the teacher account.
3. Create a Grade 7 English assessment and save a draft score.
4. Refresh to confirm the saved score remains.
5. Preview an invalid CSV and see the row error. Preview a valid CSV and save it.
6. Publish the reviewed result.
7. Sign out and try the student account. Only the linked student's released results appear.

Administrator invitation and assignment flows are also exercised by the desktop/mobile automated browser suite. Administrator credentials are not published.

The public accounts share one fictional dataset, so later visitors may see additional assessments. See the [README](../README.md#try-it) for credentials and review steps.
